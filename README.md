# Avengis Games

The studio site for Avengis Games (Aven, solo developer, UK): a landing page with the montage and the games, and an about page.
Static HTML and CSS, served by GitHub Pages at https://tracedicky.github.io/avengis/.

Built from the games' own art: Rebounded's bricks and stills, The Dugout's timber board, moss, night town and footage.
The montage (`media/montage.mp4`) is cut from Rebounded's showpiece, Pocket Edition's Final Hit and a Dugout autoplay capture.
